## What it does

- Creates a **real extended display** through `CGVirtualDisplay`, not a mirror.
- Captures that display with **ScreenCaptureKit** and encodes **H.264** with
  **VideoToolbox**.
- Streams over **USB / `adb reverse`** to the unmodified upstream Android receiver.
- Sends **tap, drag and two-finger scroll** back to the Mac as pointer and scroll events.
- Installs as **user-level services**: no admin password, no kernel extension, no system
  modification.

## What changed since the internal P5q.10.12 build

This preview is not a byte-identical copy of the last internally verified bundle. It was
rebuilt from a hardened source tree, and the differences are deliberate:

| Change | Reason |
|---|---|
| `setup install` has no default ADB serial; `--serial` is required | A published build must not carry the author's tablet identity, and a fixed default would bind every installation to a device it does not own |
| The menu bar resolves the serial from `product-install.json`, else the single authorized `adb devices` entry | Removes the last hardcoded device constant from the GUI; refuses with an explanation when there is nothing to bind to |
| The shell installer requires `--serial` / `USCREEN_SERIAL` | Same reason, in the script path |
| Release build uses `--remap-path-prefix` | No builder home directory is embedded in the binary |
| Bundle version `0.2.0` / `2026.10.25` | A real version, instead of the internal build tag |

None of this changes behaviour that is reachable with a valid serial.

## Known issues

- 60 fps is not reached; capture tops out around 50–56 fps on the reference host.
- No HEVC. No pen pressure, tilt or eraser. No pinch-zoom (two fingers scroll).
- Resolution changes require a host restart.
- Not notarized; the first launch needs a per-app override.
- No Android APK is distributed with this release.
- Long sessions can stress the host graphics stack; the supervisor can stop a session.

Full list: [Limitations](../limitations.md).

## Upgrading from an internal build

1. Quit UScreen.
2. `~/Applications/UScreen/bin/uscreen-macos setup uninstall`
3. Replace `~/Applications/UScreen.app`.
4. Re-run setup with your serial, because the serial is no longer baked in:

```bash
~/Applications/UScreen/bin/uscreen-macos setup install --activate \
  --serial <your-adb-serial>
```

5. Re-grant Screen Recording and Accessibility if macOS asks again — the binary path is
   the same, but the signature changed.
